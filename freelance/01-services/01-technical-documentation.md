# Service 1: Engineering Document Automation

**Service name (EN):** Engineering Document Automation Service  
**한국어:** 기술문서 자동화 · RCA · 제안서 작성 서비스

## One-line pitch

I turn your field data, test results, and engineering notes into professional customer-facing technical documents.

## What I deliver

| Document type | Typical use |
|---------------|-------------|
| Root Cause Analysis (RCA) report | Customer issue closure, quality records |
| FAT / SAT / HAT procedure | Factory/site acceptance testing |
| Issue analysis report | Internal escalation, supplier response |
| Technical proposal draft | Bid support, scope definition |
| Installation / commissioning procedure | Field deployment |
| Trouble report (customer-facing) | OEM support, warranty claims |
| LinkedIn technical content | Thought leadership for engineering firms |

## Input I need from you

- Equipment name and model
- Problem description / symptoms
- Environment (site, vessel, rack, network)
- Test results and evidence (logs, photos, measurements)
- Root cause hypothesis (if known)
- Corrective actions taken or planned
- Verification evidence

## Process

1. **Intake** — You send raw notes, photos, test logs, or a call summary.
2. **Structure** — I map content to the right document template (RCA, FAT/SAT, proposal, etc.).
3. **Draft** — AI-assisted first draft with engineering judgment applied.
4. **Review** — You confirm facts; I refine tone and customer-facing language.
5. **Deliver** — Word/PDF final; optional Streamlit-generated draft for repeat formats.
