# 요구사항-검증 매트릭스

이 문서는 모델 기능이 실제 제품 증거로 오인되지 않도록 요구사항과 검증 단계를 연결한다.

| ID | 요구사항 | 현재 자동 증거 | 보드/HIL에서 추가할 증거 | 판정 상태 |
|---|---|---|---|---|
| FF-01 | 재료·노즐·온도별 feed-forward 프로파일 | 프로파일 JSON, 반복 shot CSV | 실제 재료 DOE, 유량/온도 추적성 | SIMULATED |
| ADP-01 | shot-to-shot 보정량과 총 gain 제한 | `test_bounded_adaptation_converges_and_never_leaves_limits` | 목표 변경·노화·압력 변동 반복 시험 | SIMULATED |
| ADP-02 | 프로파일 간 학습값 격리 | `test_profile_isolation_blocks_cross_profile_learning` | 펌웨어 NVM key 전환/복구 시험 | SIMULATED |
| ADP-03 | 총중량 학습창 이탈 시 보정 금지 | `test_high_total_error_with_valid_ratio_cannot_update_learning` | calibration/production 모드별 승인창 시험 | SIMULATED |
| ADP-04 | 신뢰도에 비례해 보정 gain 적용 | `test_confidence_blends_correction_gain` | reset/restart/저신뢰 전환 시험 | SIMULATED |
| RAT-01 | A/B 독립 계측과 허용오차 이탈 시 학습 금지 | `test_rejected_ratio_shot_cannot_update_learning` | A/B 개별 센서 주입 및 fault latch 캡처 | SIMULATED |
| NVM-01 | CRC 오류 시 이전 보정값으로 복구 | `test_crc_corruption_falls_back_to_older_slot` | 실제 Flash bit-flip/power-cycle 시험 | SIMULATED |
| NVM-02 | 저장 도중 전원 차단 시 마지막 유효값 유지 | `test_interrupted_write_preserves_current_record` | brownout jig와 전원 파형 | SIMULATED |
| ACT-01 | servo/stepper/DC/BLDC·AC 시정수·deadband·slew 차이 반영 | `test_actuator_time_constants_change_delivered_mass` | 실제 drive current/speed/position trace | SIMULATED |
| DLY-01 | 센서·수송 지연과 settling window 반영 | `last_shot_trace.csv` | ADC digital-filter delay 측정과 timestamp 정렬 | SIMULATED |
| SAFE-01 | timeout, 비율 이탈, 센서 이상에서 보정 중지 | 모델 rejection path | E-stop, watchdog, comm loss, overload 안전상태 | UNVERIFIED |
| HIL-01 | 실보드 HIL 증거 묶음 생성 | `HIL_증거_템플릿.md` | firmware hash, wiring, instruments, raw logs, pass/fail 승인 | UNVERIFIED |

`SIMULATED`는 모델 내부 동작만 확인했다는 뜻이다. 제품 성능 또는 안전 인증을 뜻하지 않는다.
