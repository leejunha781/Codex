# 태하 디스펜서 제어 실습 워크북

각 실습 결과는 SIMULATED, SIL, PIL, HIL, PHYSICAL 중 하나로 표시한다.

## 실습 1 — 기준 실행

    $env:PYTHONPATH = "$PWD\src"
    python -m taeha_dispense_sim.runner --shots 40 --output outputs/baseline

확인:

- 처음 10 shot과 마지막 10 shot의 절대 오차 비교
- gain A/B가 absolute/rate limit를 지키는지
- ratio error와 total error의 차이
- summary.json, shots.csv, last_shot_trace.csv, PNG가 생성되는지

## 실습 2 — 학습 비활성 비교

    python -m taeha_dispense_sim.runner --shots 40 --no-adaptive --output outputs/no_adaptation

질문:

- 반복되어도 bias가 남는 이유는?
- random noise와 model bias를 어떻게 구분할 것인가?
- 보정 gain이 너무 크면 어떤 진동이 생기는가?

## 실습 3 — 온도 변화

    python -m taeha_dispense_sim.runner --temperature-c 20 --output outputs/temp20
    python -m taeha_dispense_sim.runner --temperature-c 35 --output outputs/temp35

질문:

- 현재 temperature factor는 물리 법칙인가 경험식인가?
- 실제 재료에 적용하려면 어떤 rheology/shot 데이터를 수집해야 하는가?
- 온도 band를 바꿀 때 learned state를 유지해도 되는가?

## 실습 4 — actuator 비교

A/B를 servo, stepper, brushed_dc, bldc_ac로 조합한다.

- deadband, slew, quantization이 짧은 shot에 미치는 영향
- stepper missed-step가 현재 모델에서 빠져 있다는 의미
- 외부 servo drive의 내부 loop를 식별하는 방법

## 실습 5 — 센서 지연

프로파일 사본에서 sensor.delay_s와 settle_time_s를 늘린다.

- 안정 중량을 언제 accepted로 볼 것인가?
- 출력 데이터 주기와 필터 settling의 차이는?
- in-shot PID의 가능한 bandwidth는?

## 실습 6 — A/B 비율 불량

A 또는 B의 actual_flow_scale을 크게 바꾼다.

- ratio gate가 learning을 막는가?
- total mass가 맞아도 ratio가 틀릴 수 있는가?
- 한 성분만 막혔을 때 필요한 latched fault는?

## 실습 7 — 프로파일 격리

다른 material/nozzle key를 추가하고 보정 state를 교차 적용한다.

통과 조건:

- key mismatch에서 gain은 1.0 baseline
- 다른 profile sample은 현재 profile을 update하지 않음
- temperature band/schema 변경 시 state가 quarantine됨

## 실습 8 — CRC/이중 슬롯

    python -m unittest discover -s tests -v

확인:

- 최신 slot CRC가 틀리면 이전 slot로 fallback
- write 중단 시 기존 record 보존
- 두 slot이 모두 손상되었을 때 factory/calibration-required 정책

## 실습 9 — captured-data replay

실제 보드에서 수집할 CSV:

    timestamp_us
    state
    command_A, command_B
    motor_current_A, motor_current_B
    motor_speed_A, motor_speed_B
    pressure_A, pressure_B
    raw_ADC_A, raw_ADC_B
    filtered_mass_A, filtered_mass_B
    temperature_A, temperature_B
    fault_bits
    profile_revision

동일 입력으로 model과 firmware controller를 replay하고 차이를 비교한다.

## 실습 10 — HIL 시험서

HIL_증거_템플릿.md를 복사하여 실제 board/fixture/material 정보를 채운다. 물리 시험 전에는 모든 하드웨어 결과를 UNVERIFIED로 둔다.
